# Screenshot Capture Guide

The [project README](../../README.md) uses these screenshots. Keep the same filenames when updating the images.

| File | View |
| --- | --- |
| `dashboard.png` | Weekly totals, comparison values, and the heart-rate zone chart |
| `comparison-lab.png` | Matched activities and the interactive pace trend |
| `activities.png` | Recent activities with one detail card expanded |
| `training-planner.png` | A weekly plan with structured workout phases |

Use a consistent viewport and crop to the application. Review every image for credentials, identifying details, and private training or health data before publishing.
